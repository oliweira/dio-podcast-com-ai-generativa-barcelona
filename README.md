# 🎙️ Podcast com IA Generativa: Barcelona

Projeto prático desenvolvido como parte dos desafios da **DIO (Digital Innovation One)**. O objetivo deste projeto é explorar o potencial das Inteligências Artificiais Generativas para criar todo o fluxo de produção de um podcast, desde a concepção do roteiro até a geração do áudio.

---

## 🚀 Tecnologias e Ferramentas Utilizadas
* **Gemini / Claude:** Para a estruturação e criação do roteiro do podcast.
* **ElevenLabs:** Para a síntese de voz realista baseada em IA.
* **Audacity / Ferramentas de Edição:** Para ajustes finais de trilha sonora e corte de áudio.
* **GitHub:** Para versionamento e entrega do código/projeto.

---

## 📂 Organização do Repositório
* `audio/`: Contém o arquivo final do podcast (`.mp3`).
* `prompts/`: Contém a documentação com os prompts utilizados nas IAs.
